# AEGORA v6.3 — Privacy Architecture & Data Classification Map

AEGORA adheres to strict **Data Minimization** and **Privacy by Design** principles. We never collect sensitive personal data merely because it is technically possible.

## 2. Prohibited Data Collection

AEGORA strictly prohibits the collection, transmission, or logging of:
- **Authentication Secrets**: Passwords, raw biometric data (handled exclusively by Android Keystore/TEE), TOTP seed keys.
- **Hardware Identifiers**: IMEI, MAC address, Android ID (SSAID), IMSI.
- **Location Telemetry**: Precise GPS coordinates, cell tower IDs, WiFi SSID/BSSID.
- **Private Communications**: Contact lists, SMS messages, personal files outside sandbox.
- **Advertising Trackers**: Zero third-party behavioral ad trackers or monetization SDKs.

---

## 3. User Data Rights & Controls

1. **Right of Access & Portability**: Users can export their complete learning history, project write-ups, and skill genome as a structured JSON/Markdown bundle via the **Account Center**.
2. **Right to Erasure (Account Deletion)**: One-tap local data wipe clears all preferences, progress, evidence artifacts, and cached models immediately.
3. **Telemetry Opt-Out**: Crash reporting and system diagnostics can be toggled on or off directly in settings.
