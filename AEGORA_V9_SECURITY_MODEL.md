# AEGORA v9.0 — SECURITY & ETHICAL SAFETY MODEL

## Core Principles

### 1. Educational Sandbox Isolation
All offensive security activities, exploit demonstrations, and adversary simulations are strictly:
- Confined to simulated, fictional telemetry and sandboxed environments.
- Labeled with explicit educational safety notices.
- Free of any real-world attacking capabilities or live exploits against unauthorized targets.

### 2. Honest Provenance & No Fabricated Data
- Simulated features are explicitly labeled as **SIMULATED**, **CACHED**, or **DEMO FIXTURE**.
- No fabricated "live" data or fake employment guarantees are presented.
- Epistemic uncertainty is transparently surfaced via the **AEGORA Truth Layer**.
