
## 2. Core Architectural Pillars
1. **Cyber Mission Generator (`CyberMissionV10`)**:
   - Synthesizes targeted missions based on exact time budgets (5m, 15m, 30m, 60m, 3h, multi-day) and 11 functional categories (Learn, Investigate, Defend, Attack Sandbox, Analyze, Research, Build, Explain, Communicate, Interview, Career Prep).
2. **Cyber Twin 4.0 (`CyberTwin40Snapshot`)**:
   - 16 core dimensions with explicit "WHY THIS SCORE EXISTS" breakdowns: positive/negative evidence, evidence age, quality, mistake frequency, retention trend, and prescriptive next actions.
3. **Next Best Action Engine 2.0 (`NextBestActionBundle`)**:
   - Recommends Primary Action + Options A/B/C with urgency ratings and 6 feedback triggers (Do Now, Save, Snooze, Not Relevant, Too Easy, Too Hard).
4. **Learning Science & 5-Min Skill Resurrection (`SkillResurrectionChallenge`)**:
   - Ebbinghaus-timed retrieval challenges with 5 graduated scaffolding steps (Recall → Hint → Partial Support → Answer → Root Cause Explanation → Retest).
5. **Reasoning Graph 3.0 (`ReasoningGraphAudit`)**:
   - Traces student investigative discipline against the **AEGORA Training Reference Model**, computing Evidence-First, Hypothesis Falsification, and Timeline Discipline scores.
6. **Cyber Workplace 3.0 (`WorkplaceItemV10`)**:
   - Simulates 8 corporate archetypes (FinTech, SaaS, Healthcare, University, Gov, OT/ICS, E-Commerce, AI Labs) with multi-channel inboxes (Executive Email, SIEM Alerts, Jira Tickets, Slack/Teams).
7. **Career Reality & Reverse Job Description Lab (`ReverseJobAnalysisResult`)**:
   - Evaluates 18 cyber career families, extracting Required, Preferred, and Inferred skills, verified evidence proofs, and shortest realistic pathways.
8. **AI Safety & Untrusted Data Defense (`UntrustedContentQuarantine`)**:
   - Isolates external threat reports from agent system prompts with real-time prompt injection heuristics.
