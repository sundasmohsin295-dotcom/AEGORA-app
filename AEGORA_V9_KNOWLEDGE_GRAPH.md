# AEGORA v9.0 — KNOWLEDGE GRAPH 3.0 & CONSTELLATION UNIVERSE

## Overview
Knowledge Graph 3.0 represents cybersecurity concepts, tools, protocols, threats, and career roles as an interconnected multi-dimensional ontology across 17 distinct node classes and 10 semantic edge types.

---

## 1. Node Ontology (17 Classes)
1. **CONCEPT**: Foundational theoretical paradigms (e.g., Symmetric vs. Asymmetric Crypto, Windows Process Lineage).
2. **TOOL**: Applied software systems (e.g., Sysmon, Splunk, Wireshark, Volatility).
3. **PROTOCOL**: Formal network & auth specifications (e.g., TLS 1.3, TCP, Kerberos).
4. **VULNERABILITY**: Algorithmic and implementation weaknesses (e.g., Type Confusion, Buffer Overflow).
5. **CVE**: Specific cataloged vulnerabilities (e.g., CVE-2026-4401).
6. **THREAT_ACTOR**: Nation-state & e-crime syndicates (e.g., Volt Typhoon, APT29).
7. **MALWARE**: Tooling and payloads (e.g., Mimikatz, Cobalt Strike).
8. **TECHNIQUE**: MITRE ATT&CK categorized actions (e.g., T1047 WMI, T1558 Kerberoasting).
9. **DETECTION**: Signature & heuristic rules (e.g., Sigma rules, YARA rules).
10. **FRAMEWORK**: Compliance & taxonomy standards (e.g., MITRE ATT&CK, NIST CSF, ISO 27001).
11. **CAREER**: Industry job roles (e.g., SOC Analyst L1/L2, Threat Hunter, DevSecOps).
12. **CERTIFICATION**: Industry credentials (e.g., CompTIA Security+, OSCP, CISSP).
13. **LAB**: Hands-on sandbox drills (e.g., Sysmon Process Injection Lab).
14. **PROJECT**: Portfolio capstones with GitHub deliverables (e.g., Enterprise Sigma Engine).
15. **INCIDENT**: Historical case studies and breach retrospectives.
16. **COMPANY**: Sector archetypes (e.g., FinTech, SaaS, Healthcare).
17. **RESEARCH_PAPER**: Peer-reviewed publications (e.g., NIST FIPS 203 ML-KEM).

---

## 2. Semantic Edge Types (10 Classes)
- `REQUIRES`: Strict prerequisite dependency.
- `RELATED_TO`: Conceptual association.
- `DETECTED_BY`: Defensive telemetry correlation.
- `EXPLOITED_BY`: Weaponization mechanism.
- `USED_IN`: Functional deployment in architecture.
- `TEACHES`: Educational instructional delivery.
- `PRACTICED_BY`: Hands-on lab / capstone reinforcement.
- `RELEVANT_TO`: Career pathway requirement.
- `PRECEDES`: Sequence in adversary attack chain.
- `CONTRADICTS`: Mutually exclusive hypotheses in incident triage.
